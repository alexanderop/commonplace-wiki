# Answer from the wiki

This workflow is read-only unless the user asks to save the answer.

1. Search authored Markdown using specific terms, synonyms, tags and source authors. Include private notes for the owner's local question; restrict to public notes when preparing an answer for publication.
2. Read matching notes and their cited source notes. Distinguish a source claim from an existing interpretation. Follow additional links when needed rather than imposing a fixed result count.
3. Give a direct answer with note references attached to substantive claims. Preserve disagreements and uncertainty. If the collection does not answer the question, identify the missing evidence; do not silently substitute general knowledge or external search for the user's notes.
4. If broader research was requested, distinguish newly retrieved evidence from the existing collection. Do not save it without a capture request.
5. If asked to save the answer, create or update a private insight using the [note contract](../references/note-contract.md), cite supporting note IDs, and follow [validation](../../wiki-validate/SKILL.md).

Done means a traceable answer and explicit gaps. Answering alone does not modify files or the activity log.
