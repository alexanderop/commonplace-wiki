# Capture an article or documentation page

1. Inspect source identity and duplicates with [source extraction](../../wiki-extract-source/SKILL.md). Retrieve readable text through an available browser/fetch tool or supplied file. Keep the requested and final URL in raw provenance when redirects differ.
2. Read the actual text. Extract the claim, supporting reasoning, examples and caveats; distinguish the article from comments or surrounding navigation. For versioned documentation, preserve the version and retrieval date. For PDFs, use available text extraction and retain page references only when known.
3. If access is blocked or only an excerpt is available, mark coverage accurately. A search snippet or abstract does not establish a full article summary. Save a pending source rather than invent missing content.
4. Use [connection discovery](../../wiki-connect-notes/SKILL.md) to update relevant existing knowledge. Write using the [note contract](../references/note-contract.md), with `resourceType: blog` for articles or `documentation` for documentation.
5. Follow [validation](../../wiki-validate/SKILL.md). Report what was read and what was not, alongside the changed note IDs.

Completion is a supported, reusable source note integrated into the existing collection. A mirrored URL or renamed article is a duplicate candidate, not automatic proof that it is a different source.
