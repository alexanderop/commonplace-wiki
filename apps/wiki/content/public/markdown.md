## Der Text bleibt
Eine Markdown-Datei enthält den eigentlichen Gedanken. Sie lässt sich mit einem Texteditor lesen und mit Git versionieren. Eine neue Oberfläche muss diesen Bestand nicht ersetzen.

## Metadaten geben Orientierung
Titel, Typ, Themen und Datum stehen im Frontmatter. Links im Text machen Beziehungen sichtbar. [Vernetzte Notizen](/notes/vernetzte-notizen) entstehen aus diesen einfachen Bausteinen.

## Darstellung darf mehr können
Mit [Comark](/notes/comark) können ausgewählte Vue-Komponenten den Text ergänzen. Eine Quellenkarte oder eine hervorgehobene Erkenntnis bekommt eine eigene Darstellung.

Der Gedanke sollte auch dann verständlich sein, wenn eine besondere Komponente außerhalb dieser App nicht dargestellt wird.
