# Source inbox

Place source text, transcripts or articles here. Preserve original files after ingestion. This inbox is ignored by Git; keep a separate private backup. Record private ingestion activity in `raw/wiki-log.md`, also ignored. This directory is never included in the website build.

The wiki agent uses the ingestion rules in the root AGENTS.md. The website reads only compiled notes from apps/wiki/content/public (or both content folders in a personal edition).
